# pdf2imageweb
HTML上だけでPDFをイメージに分割するツールです。

## 使い方

1. リストにPDFファイルを追加してください。PDFはファイル選択ボックスからのファイル選択またはファイルのドロップにより追加できます。
2. 追加すると、PDFの各ページが画像化されてプレビュー表示されます。各ページの「回転（時計回り）」から90°・180°・270°を選択できます。0°を選ぶと元の向きに戻ります。回転はマージ前の各ページに適用され、並び替え後も保持されます。
3. リストの項目を選択すると、そのPDFのページを確認できます。「すべてダウンロード」より、回転・並び替え・マージを反映したPDFとPNG画像をフォルダに収めたZIPファイルがダウンロードできます。

## PWA対応

このツールはProgressive Web Appsに対応しています。インターネットに接続していない時でも動作が可能です。

インターネット上に最新データがあった場合は、「更新データがあります」というメッセージが表示されます。
